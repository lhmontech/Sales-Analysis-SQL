# Sales Analysis with SQL

## Description

This project simulates a sales database and performs SQL analysis to extract business insights such as revenue, ticket average, top-selling products and sales trends over time.

## 🎯 Objective

Practice SQL queries focused on business analysis and KPIs commonly used by Data Analysts.

## 🗃️ Data Model

The database contains:
- Customers
- Games
- Orders
- Order Items

Each order can contain multiple games, and each game belongs to a genre.

## 📊 Business Questions Answered

- How much does the enterprise revenue per month?
- Which month has the highest number of orders?
- Which game sells the most?
- Which game genre sells more?
- What is the average order value (ticket)?

## 🛠️ Technologies

- MySQL
- SQL

## ▶️ How to Run

1. Create the database using `schema.sql`
2. Populate the tables using `inserts.sql`
3. Run the analysis queries in `queries.sql`
